AutoClip is a personal tool that turns long recorded gaming live streams into short vertical highlight clips and uploads them to the operator's own YouTube channel, ViceCity.

How it works

  1. When a followed streamer's broadcast ends, AutoClip transcribes the recording on the operator's computer and picks the strongest moments.
  2. It renders each moment as a 1080x1920 clip with captions and a credit to the original streamer.
  3. It uploads the finished clip to the operator's channel with the YouTube Data API (videos.insert), using the operator's own Google sign-in (OAuth 2.0, scope youtube.upload).

AutoClip uses YouTube API Services. By using AutoClip you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy and our Privacy Policy.

AutoClip is not distributed to the public: it runs only on the operator's computer and only uploads to the operator's channel.
