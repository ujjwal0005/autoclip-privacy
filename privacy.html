AutoClip Privacy Policy

Last updated: November 19, 2026

YouTube API Services

AutoClip uses YouTube API Services to upload videos to YouTube. By using AutoClip you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What information AutoClip accesses

AutoClip asks for one Google permission, https://www.googleapis.com/auth/youtube.upload, which lets it upload videos to the YouTube channel of the person who signs in. Through YouTube API Services, AutoClip only sends video files and their title, description and privacy setting, and receives the new video's ID. It does not read, collect or store any other YouTube or Google account data, viewer data, comments or analytics.

How information is used

The sign-in is used only to upload clips that the operator made to the operator's own channel.

How information is stored

The OAuth token is stored only in a file on the operator's own computer. AutoClip has no server, no database and no cloud storage, and stores no data from YouTube API Services beyond the IDs of videos it uploaded (kept in a local log file).

Sharing

AutoClip does not share, sell or transfer any user data to third parties, and does not use it for advertising. The only party that receives data is Google, through YouTube API Services.

Cookies and device data

AutoClip does not use cookies and does not store or access information on users' devices other than the local token and log files described above.

Deleting your data and revoking access

  • Revoke AutoClip's access at any time on the Google security settings page: https://security.google.com/settings/security/permissions.
  • Deleting the local token file removes AutoClip's stored credentials immediately.
  • If access is revoked, AutoClip stops all API calls and deletes stored API data within 7 days. Stored API data is also refreshed or deleted at least every 30 days.

Contact

Questions or deletion requests: open an issue at github.com/ujjwal0005/autoclip-privacy/issues.
